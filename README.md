# 🎮 Windows 11 Gaming Optimization Script

### PowerShell – Performance Boost with Full Rollback

---

## 🇧🇷 Português

### 🚀 O que é este projeto?

Este projeto contém **scripts em PowerShell** que **otimizam o Windows 11 para jogos**, melhorando:

* FPS
* Estabilidade
* Tempo de resposta (input lag)
* Redução de travamentos (stutter)

👉 **Não exige conhecimento técnico**
👉 **Não instala programas**
👉 **Possui rollback completo (100% reversível)**

---

### 📁 Arquivos do projeto

| Arquivo                        | Função                        |
| ------------------------------ | ----------------------------- |
| `optimize-windows11-gamer.ps1` | Aplica otimizações para jogos |
| `rollback-windows11-gamer.ps1` | Desfaz todas as otimizações   |

---

### ⚙️ O que o script de otimização faz?

* Ativa plano de energia **Máximo Desempenho**
* Desativa Xbox Game Bar / Game DVR
* Reduz latência em jogos online
* Dá prioridade máxima para jogos
* Desativa efeitos visuais desnecessários
* Limpa cache da memória RAM (Standby Memory)
* Desativa serviços que causam stutter

---

### 🛠️ Como usar (Passo a passo)

#### ✅ 1. Baixar os arquivos

* Clique em **Code**
* Clique em **Download ZIP**
* Extraia a pasta no computador

---

#### ✅ 2. Executar a otimização

1. Clique com o botão direito em
   `optimize-windows11-gamer.ps1`
2. Clique em **Executar com PowerShell**
3. Clique em **Sim** quando pedir permissão
4. Aguarde o script finalizar
5. **Reinicie o computador**

---

#### ♻️ Como desfazer (Rollback)

1. Clique com o botão direito em
   `rollback-windows11-gamer.ps1`
2. Execute com PowerShell
3. Reinicie o PC

Tudo volta ao padrão do Windows.

---

### ⚠️ Avisos importantes

* Compatível apenas com **Windows 11**
* Recomenda-se reiniciar o PC após executar os scripts
* Use por sua conta e risco

## 🇺🇸 English

### 🚀 What is this project?

This project contains **PowerShell scripts** designed to **optimize Windows 11 for gaming**, improving:

* FPS
* Stability
* Input responsiveness
* Reducing stutter and freezes

👉 **No technical knowledge required**
👉 **No third-party software installed**

---

### 📁 Project files

| File                           | Purpose                          |
| ------------------------------ | -------------------------------- |
| `optimize-windows11-gamer.ps1` | Applies gaming optimizations     |
| `rollback-windows11-gamer.ps1` | Restores all settings to default |

---

### ⚙️ What does the optimization script do?

* Enables **Maximum Performance** power plan
* Disables Xbox Game Bar / Game DVR
* Reduces latency for online gaming
* Sets maximum priority for games
* Disables unnecessary visual effects
* Cleans RAM cache (Standby Memory)
* Disables services known to cause stutter

---

### 🛠️ How to use (Step by step)

#### ✅ 1. Download the files

* Click **Code**
* Click **Download ZIP**
* Extract the folder to your PC

---

#### ✅ 2. Run the optimization

1. Right-click on
   `optimize-windows11-gamer.ps1`
2. Click **Run with PowerShell**
3. Click **Yes** when prompted
4. Wait for the script to finish
5. **Restart your PC**

---

#### ♻️ How to rollback (Restore)

1. Right-click on
   `rollback-windows11-gamer.ps1`
2. Run with PowerShell
3. Restart your PC

All settings will be restored to default.

### ⚠️ Important notes

* Compatible with **Windows 11 only**
